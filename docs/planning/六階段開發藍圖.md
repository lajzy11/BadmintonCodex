**🟢 Version 1 (TA: 團主) — 核心：手動匯入名單，系統自動排點**

此階段重點在於建立排點的核心引擎與團主端的操作介面：

* 名單手動登錄/匯入：團主可在排點系統上手動登錄或匯入當天報名的人員名單。
* 自動排點引擎：系統會根據自動輪播、級數落差、等待時間、已打場數、男女/混雙偏好等條件，自動算出一組建議的上場名單，藉此減輕團主排點時的心力負擔。
* 排點參數設定與客製化：團主可設定排點規則（如跨級上限、組對重複率、雙打型態偏好），並可標記成員間\*\*「避免同場」（迴避名單）與「優先同場」\*\*的關係，減少人際衝突且不需每次靠大腦記憶。
* 拖曳調整 UI：提供類似 POS 機（如 inline 系統）的直覺卡牌拖曳介面，方便團主直接將成員卡牌拖曳至特定球場進行微調。
* 現場客製化綁定設定：在排點介面上長按成員，可觸發\*\*「互相綁定、綁一場、打一場、減少同組」\*\*等現場即時微調設定。
* 自動場地調整與限制：系統能根據名單人數自動計算並調整場地數量（例如每滿 8 人提示可加開 1 面場地），或可針對特定球場設定級數/組別限制。

**🟢 Version 2 (TA: 團主) — 核心：手動辦理報到**

此階段增加團主現場點收費用、報到與流水分流的管理功能：

* 團主手動報到管理：團主可在系統上直接點擊確認球友已到場，手動將其由名單移至「備戰區」。此功能可取代人潮尖峰時逐一在紙本找名字核對的耗時流程。
* 方案與金額記錄：開場前在系統上記錄成員當天的零打方案（應付款金額、打球時間）、付款方式與級數。
* 付款管道標記與分流：記錄並分流現金、轉帳與 Line Pay 收費，系統會自動加總金額，以利事後與共同經營的團主共用同份帳務，免去結束後口頭重新對帳的麻煩。
* 未到帳務追蹤：記錄「報名未到成員」的收費與款項處理狀態（如已收費、待收費或不予追究），避免灰色地帶與帳務不清。

**🟢 Version 3 (TA: 球員) — 核心：自行掃碼報到**

此階段首次引入球員端操作，以數位化簡化現場報到流程：

* 球員自主掃碼報到：球員抵達現場後，可使用手機直接掃描現場的 QR Code 辦理報到，降低團主現場邊記帳邊排點的手忙腳亂。
* 免帳號認領身分機制：尚未註冊系統帳號的零打球友，可直接透過掃描 QR Code 進入當次活動網頁，並認領 LINE/FB 接龍名單中的對應身分，確保沒有帳號的人也能使用基本的即時查看功能。

**🟢 Version 4 (TA: 團主、球員) — 核心：團主系統開團，球員系統報名**

此階段建立起完整的賽前開團與線上報名機制：

* 團主線上開團與複製功能：團主可在系統上開設新場次，支援複製過往活動或設定循環自動開團，並能一鍵開放下週報名入口。
* 統一零打報名網頁入口（網頁 \& RWD）：球員可用網頁快速入口瀏覽各球團活動、線上預約，並可綁定 LINE 帳號接收預約推播通知，解決報名資訊分散於多個群組且通知易被遺漏的痛點。
* 帳號註冊與個人綁定：球員註冊個人帳號，綁定個人資料（如手機、帳戶等）以避免每次重複填寫。
* 報名自訂選項與限制：球員報名時可自填級數、性別、特殊資歷（如校隊、體保），以及\*\*「是否願意被拍攝」\*\*的意願設定（解決不想被攝影又不好意思說出口的隱私問題）。
* 主觀/客觀資訊修改：團主可事後修改與備註球友的級數、性別、出席率、跟誰配過等資訊。
* 觀察與私人備註：團主可記錄成員的性格、特定要求、球風、偏好站位、身體狀況（例如體力、是否剛受傷復出）等私人備註。
* 球友資格審查與限制：團主可設定特定報名規則，例如限制必須有帳號者才能報名、限制到場率達特定 % 數之球友報名，或在級數說明欄限制不合規的球友報名。
* 名單自動同步：報名系統與排點系統的名單直接打通，無需團主人工謄寫或重複匯入。

**🟢 Version 5 (TA: 球員) — 核心：手機同步查看排點資訊與對戰紀錄**

此階段大幅提升球員在場邊的互動體驗，將現場即時資訊同步給球員：

* 手機即時看板：球員可在手機上同步查看排點資訊、下一場配對、場地等待組數，以及確認目前是否輪到自己，解決現場吵雜、團主需要重複喊人找人的困擾。
* 自身歷史與比分記錄：球員可查看自己的對戰紀錄、已打場次與已等待時間，讓排點資訊公開透明，減少對團主公平性的爭議與不滿。
* 回報比分與場地狀況：球友可於手機端自行回報各場比分，並可回報現場空場、缺人等即時場地狀況。
* 球友互評與黑名單機制：球友可設定「減少同組/同場」的黑名單，並能對配合度佳的好隊友給予鼓勵互評，配合不佳者則減少配對。
* 場邊社群互動：開放球友端 PO 文功能，並提供場邊小遊戲（需為排到點時能隨時暫停或立刻結算的類型），增加下場後的交流機會。
* 小知識庫與用量統計：
* 羽球知識庫：提供受傷處理、判賠、斷拍糾紛處理等羽球小知識。
* 羽球用量數據統計：提供團主簡單的羽球消耗數據統計與需求推測，方便團主定期補貨與對帳。
* 成員狀態即時標記（雙端）：團主或球友能即時標記暫離（如抽菸、廁所）、受傷或臨時下場等狀態，避免排點系統誤將其排入下一場。
